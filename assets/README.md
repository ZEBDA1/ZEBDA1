# Bannières du profil

`zebda-banner.svg` et `zebda-footer.svg` sont des compositions vectorielles locales : texte, géométrie et palette graphite/bleu de la présentation renouvelée. Elles ne contiennent aucun script, suivi externe ou ressource distante. La bannière promotionnelle ImmoAlert est servie depuis les assets publics du dépôt ImmoAlert.

## Statistiques de contributions

`github-streak.svg` est généré chaque jour à 03:15 UTC par `.github/workflows/streak-stats.yml`, avec l’action officielle GitHub Readme Streak Stats fixée sur un commit vérifié. Le README lit le fichier du dépôt et ne dépend plus du service public d’images.

Le workflow utilise uniquement le jeton temporaire fourni par GitHub Actions pour ce dépôt, sans PAT personnel. Il valide l’image avant de l’enregistrer ; si la génération échoue, le dernier fichier valide est conservé. Une mise à jour manuelle est possible depuis l’onglet Actions.
